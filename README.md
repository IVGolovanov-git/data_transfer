# Перезапись файла

Программа считывает содержимое файла - источника, добавляет к считанным строкам порядковый номер и сохраняет их в таком виде в новый файл.

Для разделения содержимого файла на строки, используется функция readlines()

# File overwrite

The program reads the contents of the source file, adds a sequence number to the read lines, and saves them in that form to a new file.

To split the file contents into lines, the readlines() function is used
